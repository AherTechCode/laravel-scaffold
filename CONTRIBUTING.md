# Contributing Guidelines

Thank you for your interest in Laravel Scaffold.

This project prioritizes:
- stability
- clarity
- backward compatibility
- opinionated architecture

## Before Submitting a Pull Request

Please:
1. Open an Issue describing the problem or idea
2. Discuss the approach before writing code
3. Keep changes focused and minimal

## What Is Likely to Be Accepted

- Bug fixes
- Performance improvements
- Documentation updates

## What Requires Prior Discussion

- New features
- Changes to DSL syntax
- Architectural refactors

## Project Governance

Laravel Scaffold follows a Benevolent Dictator For Life (BDFL) model.
The maintainer retains final decision-making authority to ensure
long-term consistency and quality.

All pull requests are reviewed at the discretion of the maintainer.
